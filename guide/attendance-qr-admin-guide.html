SPEC 출석 QR/코드 운영 가이드

매주 금요일 세션에서 운영진이 QR과 6자리 코드를 발급하고, 참석자가 직접 출석 체크하며, 운영진이 최종 출석표를 보정하는 절차를 정리했습니다.

대상: 비개발자 운영진 사용 화면: 관리자 출석 관리, QR 보드, 참석자 출석 체크 생성일: 2026-06-09

SPEC Attendance

한눈에 보는 운영 흐름

  • 운영진 계정으로 로그인한 뒤 출석 관리 화면을 엽니다.
  • 오늘 진행할 세션의 출석 시작/오픈/마감 시간을 확인합니다.
  • 코드를 발급하고 QR 보드를 앞 슬라이드 또는 프로젝터에 띄웁니다.
  • 참석자는 QR 또는 6자리 코드로 직접 출석 체크합니다.
  • 세션 종료 후 출석을 닫고 예외 인원만 운영진이 수동 보정합니다.

SPEC Attendance

세션 시작 전 준비

  • 세션 제목과 날짜가 맞는지 확인합니다.
  • 시작 시간은 실제 세션 시작 시간을 입력합니다.
  • 오픈 시간은 사람들이 체크인을 시작해도 되는 시간을 입력합니다.
  • 마감 시간은 지각 기준 또는 체크인 종료 기준에 맞춰 입력합니다.

SPEC Attendance

출석 코드 발급

  • 활성 체크박스를 켠 뒤 저장을 누릅니다.
  • 코드 발급을 누르면 6자리 코드와 QR 링크가 생성됩니다.
  • 코드가 노출되었거나 잘못 발급했다면 재발급을 눌러 새 코드로 바꿉니다.
  • 링크 복사는 메신저 공지용, 보드 열기는 현장 화면 공유용입니다.

SPEC Attendance

QR 보드 띄우기

  • 보드 열기를 눌러 큰 QR 화면을 엽니다.
  • 프로젝터나 슬라이드 공유 화면에 QR과 6자리 코드가 모두 보이게 둡니다.
  • 참석자가 QR을 찍기 어렵다면 화면의 6자리 코드를 직접 입력하게 안내합니다.

SPEC Attendance

참석자 체크인 확인

  • 참석자는 로그인된 계정으로 QR 링크에 접속합니다.
  • 코드가 미리 입력되어 있으면 출석 체크 버튼만 누르면 됩니다.
  • 코드를 직접 입력하는 경우 6자리 숫자를 입력한 뒤 출석 체크를 누릅니다.
  • 이미 운영진이 수동 기록한 인원은 직접 체크인으로 덮어쓰지 않습니다.

SPEC Attendance

마감과 수동 보정

  • 세션이 끝나면 닫기를 눌러 추가 직접 체크인을 막습니다.
  • 지각/결석/공결처럼 사유가 필요한 상태는 운영진이 표에서 직접 수정합니다.
  • 전원 출석 버튼은 현장 확인이 끝난 뒤 필요한 경우에만 사용합니다.

SPEC Attendance

자주 생기는 문제

  • 참석자가 코드 오류를 보면 최신 보드의 6자리 코드와 같은지 먼저 확인합니다.
  • 체크인 버튼이 비활성화되어 있으면 오픈/마감 시간이 맞는지 확인합니다.
  • QR이 잘 안 찍히면 링크 복사 대신 6자리 코드 입력을 안내합니다.
  • 수동 기록과 직접 체크인이 충돌하면 운영진 기록이 우선입니다.
